**MugEXTR** is a powerful yet lightweight mobile utility designed for M.U.G.E.N creators and fans. It simplifies the process of extracting, organizing, and converting essential game assets from raw M.U.G.E.N engine files, making game development, modding, and resource gathering faster and more efficient.

---

## 🚀 Key Features

MugEXTR is built around specific, essential workflows for M.U.G.E.N resource extraction.

| Feature | Description | Related Formats |
| :--- | :--- | :--- |
| **SFF Extractor** | Instantly unpacks all sprite sheets and individual images from .SFF character and stage files into an organized folder structure. | `.SFF` ➡ `PNG`s |
| **SND Extractor** | Extracts high-quality audio effects, voice lines, and music tracks directly from .SND files. | `.SND` ➡ `WAV`s/`MP3`s |
| **FNT Extractor** | Dissects custom M.U.G.E.N .FNT font packages, allowing access to individual character glyphs. | `.FNT` ➡ `PNG`s/`TXT` data |
| **PCX to PNG Converter** | Batch-converts legacy PCX image files (common in older M.U.G.E.N packs) into modern, web-friendly PNG images. | `.PCX` ➡ `PNG` |

## 🛠️ How to Use

1.  **Select Tab:** Navigate to the specific file type you wish to work with (SFF, SND, FNT, or PCX→PNG) using the top navigation bar.
2.  **Pick Source:** Use the file picker button (e.g., "Pick SFF File", "Choose PCX Folder") to select your input file(s).
3.  **Choose Destination:** Tap "Choose Output Folder" to specify where the extracted/converted files should be saved.
4.  **Action:** The large button at the bottom (e.g., "Extract" or "Convert to PNG") will activate. Tap it to begin. Progress is typically shown in the large output log area below.
